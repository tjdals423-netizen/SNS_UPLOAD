# SNS 업로드 봇

폰에서 구글 폼으로 영상과 글을 보내면, PC 봇이 계정(민아살림 / 은조네키친 / 예쁜살림)별로
**유튜브 · 인스타 · 페이스북 · 쓰레드 · 틱톡**에 올리고, 댓글을 달고, 텔레그램으로 알려줍니다.

| 플랫폼 | 들어가는 글 | 업로드 후 상태 | 댓글 |
|---|---|---|---|
| 유튜브 | 유튜브 제목 (설명란 비움) | **비공개** → 직접 공개 전환 | 20분 안에 공개하면 자동 |
| 인스타 | 공통 본문 | 바로 공개 | 항상 고정 문구 (`instagram_comment`) |
| 페북 | 공통 본문 | 바로 공개 | 폼 `댓글` 칸 기준 |
| 쓰레드 | 공통 본문 (500자 넘으면 잘림) | 바로 공개 | 폼 `댓글` 칸 기준 (내 답글) |
| 틱톡 | 틱톡 본문 (텔레그램으로 따로 옴) | **초안** → 틱톡 앱에서 게시 | 지원 안 됨 |

---

## 매일 쓰는 법
1. 폰에서 폼 열기 → 계정 선택, 영상, 유튜브 제목, 본문, 틱톡 본문, 플랫폼, 댓글(숫자) 입력 → 제출
2. 1~3분 뒤 텔레그램에 `✅ 계정 ○○ 업로드` 알림
3. 마무리 두 가지
   - **유튜브**: YouTube Studio 에서 비공개 → 공개 (**20분 안에** 하면 댓글도 자동으로 달림)
   - **틱톡**: 틱톡 앱 → 아래 **메시지(💬)** → **시스템 알림** → 업로드 알림 열기 → 텔레그램으로 온 본문 붙여넣고 게시

텔레그램에 `/status` 를 보내면 봇 상태와 최근 업로드 5건을 볼 수 있습니다.

## ⚠️ 운영하면서 유의할 점

### 1. 폼은 함부로 고치지 않기
봇은 **폼 질문 제목과 선택지 글자**를 보고 내용을 읽습니다. 글자 하나만 달라도 그 칸을 못 읽습니다.
- 질문 제목: `계정`, `영상`, `유튜브 제목`, `본문 (인스타·쓰레드·페북)`, `틱톡 본문`, `플랫폼`, `댓글`
- 플랫폼 선택지: `인스타`, `쓰레드`, `페이스북`, `유튜브`, `틱톡`
- 계정 선택지: `민아살림`, `은조네키친`, `예쁜살림`
- 바꾸고 싶으면 `bot/config.yaml` 의 `columns`, `platform_labels`, `account_labels` 도 **똑같이** 바꾸고 봇을 껐다 켜기
- 사용하는 폼은 **tjdals423@gmail.com 소유 폼**입니다. 영상은 폼 주인의 드라이브에 저장되므로 다른 계정 폼을 쓰면 영상을 못 찾습니다.
- `영상` 질문을 지웠다 다시 만들면 시트에 `영상` 열이 하나 더 생기는데, 봇은 오른쪽(새) 열을 읽으므로 그대로 둬도 됩니다.

### 2. 시트의 봇 전용 열은 지우지 않기
`상태`, `결과_유튜브`, `결과_인스타`, `결과_페북`, `결과_쓰레드`, `결과_틱톡` 열은 봇이 기록용으로 씁니다.
- **다시 올리고 싶으면** 해당 `결과_…` 칸만 지우면 다음 확인 때 그 플랫폼만 다시 올립니다.
- 실패한 건은 **10분 간격으로 최대 3번** 자동 재시도합니다. 3번 다 실패하면 원인을 해결한 뒤 칸을 지워 주세요.

### 3. 드라이브 원본은 자동으로 지워짐
5곳 업로드가 **모두 성공하면** 폼으로 올린 원본 영상을 드라이브에서 **영구 삭제**합니다 (복구 불가).
- 원본 영상은 폰이나 편집 PC 에 따로 보관하세요.
- 하나라도 실패한 영상은 재시도를 위해 남겨둡니다.
- 무료 드라이브는 15GB 입니다. 실패한 영상이 쌓이면 가끔 확인해 주세요.

### 4. 유튜브 하루 업로드 한도
유튜브 API 는 **구글 클라우드 프로젝트 하나당 하루 약 6개** 업로드 한도가 있습니다 (채널 3개를 합쳐서).
- 넘으면 `결과_유튜브` 에 `quotaExceeded` 오류가 납니다.
- 한도는 **매일 오후 4~5시(한국 시간)** 에 초기화됩니다. 초기화 후 `결과_유튜브` 칸을 지우면 다시 올라갑니다.
- 더 많이 올려야 하면 구글 클라우드 콘솔에서 할당량 증가를 신청할 수 있습니다.

### 5. 계정 연결 유지 (토큰 만료)
봇이 **하루 한 번** 모든 연결을 점검하고 쓰레드·틱톡 연결은 자동 연장합니다. 문제가 생기면 텔레그램으로 `🔑 계정 연결 점검` 알림이 오고, 어떤 setup 번호를 다시 하면 되는지 알려줍니다.

| 플랫폼 | 만료 | 할 일 |
|---|---|---|
| 구글 · 유튜브 | 거의 없음 | 비밀번호 변경·연결 해제 시에만 setup 1·2번 |
| **페북 · 인스타** | **약 90일** | 알림이 오면 그래프 API 탐색기에서 사용자 토큰(권한 8개)을 새로 받아 setup 3번 |
| 쓰레드 | 60일 | 자동 연장 |
| 틱톡 | 1년 | 자동 연장 |

이럴 때도 다시 연결해야 합니다.
- 페이스북·구글 **비밀번호를 바꿨을 때**
- 각 앱 설정에서 **연결된 앱을 삭제**했을 때
- Meta 앱의 **쓰레드 테스터**, 틱톡 샌드박스의 **Target Users** 에서 계정을 뺐을 때

### 6. 봇은 한 PC 에서만
회사 PC 와 집 PC 에서 **동시에** 켜두면 같은 영상이 두 번 올라갈 수 있습니다.
- 지금 어느 PC 에서 돌고 있는지는 `/status` 의 `PC:` 줄로 확인
- 다른 PC 로 옮기면 기존 PC 는 `stop_bot.bat` 으로 끄고, 시작 프로그램(`shell:startup`)의 바로가기도 지우기

### 7. 비밀 정보 관리
- `bot/config.yaml`, `bot/secrets/` 에는 모든 계정의 로그인 정보가 있습니다. **절대 GitHub·카톡 단체방 등에 올리지 마세요.** (GitHub 에는 자동으로 안 올라가게 막혀 있습니다.)
- 텔레그램 봇 토큰이 유출됐다면 @BotFather → `/revoke` 로 새 토큰을 받아 `config.yaml` 에 넣고 setup 6번
- 이 저장소는 **공개**라서 코드는 누구나 볼 수 있지만, 비밀 정보가 없으면 아무것도 할 수 없습니다.

### 8. 개발자 앱 설정은 그대로 두기
- Meta 앱, 쓰레드 앱, 틱톡 앱은 **개발 모드 / 샌드박스** 그대로 둬야 합니다. 정식 심사·라이브 전환은 필요 없습니다.
- 틱톡은 심사 전이라 **바로 게시가 안 되고 초안으로만** 보냅니다 (틱톡 정책).
- 구글 클라우드의 OAuth 동의 화면은 **프로덕션** 상태를 유지해야 합니다 (테스트로 바꾸면 7일마다 로그인이 풀림).

## 실행 / 끄기
| 파일 | 하는 일 |
|---|---|
| `bot/start_bot.bat` | **백그라운드로 실행** (창 없음). 텔레그램에 "업로드 봇 시작" 알림 |
| `bot/stop_bot.bat` | 백그라운드 봇 끄기 |
| `bot/start_bot_console.bat` | 창을 띄워서 실행 (오류 확인용) |
| `bot/setup.bat` | 계정 연결 메뉴 (1 구글 · 2 유튜브 · 3 페북+인스타 · 4 쓰레드 · 5 틱톡 · 6 텔레그램 · 7 점검) |

- 이미 켜져 있으면 두 번 실행되지 않습니다.
- **PC 켤 때 자동 실행**: `Win + R` → `shell:startup` → 열린 폴더에 `start_bot.bat` 바로가기 넣기
- 설정(`config.yaml`)을 바꾼 뒤에는 `stop_bot.bat` → `start_bot.bat` 으로 껐다 켜야 적용됩니다.

## 자주 쓰는 설정 (`bot/config.yaml`)
| 설정 | 설명 |
|---|---|
| `comment_template` | 유튜브·페북·쓰레드 댓글. 폼 `댓글` 칸에 숫자를 쓰면 `{번호}` 자리에 들어감. 문장을 쓰면 그대로 달림 |
| `instagram_comment` | 인스타는 항상 이 문구로 댓글 |
| `youtube.comment_wait_minutes` | 업로드 후 이 시간(분) 안에 유튜브를 공개로 바꾸면 댓글 자동 (기본 20) |
| `youtube.privacy` | 유튜브 업로드 공개 범위 `private` / `unlisted` / `public` |
| `drive_cleanup` | `delete` 성공 시 원본 영구 삭제 / `trash` 휴지통 / `off` 그대로 |
| `tiktok.mode` | `inbox` 틱톡 초안으로 보내기 (기본, 바꾸지 마세요) |
| `poll_seconds` | 시트 확인 주기(초), 기본 60 |
| `ai.anthropic_api_key` | 넣으면 빈 글 칸을 AI 가 작성 (선택) |

## 다른 PC 로 옮길 때 (집 PC 등)
1. [python.org](https://www.python.org/downloads/) 에서 파이썬 설치 — 첫 화면의 **"Add python.exe to PATH" 꼭 체크**
2. 이 저장소를 **Code → Download ZIP** 으로 받아 `C:\SNS_UPLOAD` 에 압축 해제 (안에 바로 `bot` 폴더가 보이게)
3. 기존 PC 의 `bot/config.yaml` 과 `bot/secrets/` 폴더를 같은 위치에 복사 (USB / 카톡 나에게 보내기 등 **나만 받는 곳**으로)
4. `bot/start_bot.bat` 실행 → 처음엔 설치 때문에 1~2분 → 텔레그램에 "업로드 봇 시작" 오면 완료
5. (선택) `shell:startup` 에 `start_bot.bat` 바로가기 넣기
6. 기존 PC 의 봇은 끄고 자동 실행 바로가기도 지우기 (위 6번)

## 새 버전으로 업데이트할 때
1. `stop_bot.bat` 으로 봇 끄기
2. GitHub 에서 ZIP 을 받아 `C:\SNS_UPLOAD` 에 **덮어쓰기** (`config.yaml`, `secrets/` 는 ZIP 에 없으므로 그대로 유지됨)
3. `start_bot.bat` 실행

## 계정을 하나 더 늘릴 때
1. 폼의 `계정` 선택지에 새 이름 추가
2. `config.yaml` 의 `account_labels` 에 `새이름: 새이름` 추가
3. Meta 앱 쓰레드 테스터, 틱톡 샌드박스 Target Users 에 새 계정 추가
4. `setup.bat` → 2·3·4·5번으로 새 계정 연결 → 7번 점검
5. 봇 껐다 켜기
