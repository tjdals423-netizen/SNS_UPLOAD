# SNS 업로드 봇

폰에서 구글 폼으로 영상 + 글을 보내면, PC 봇이 계정(A/B/C)별로
**유튜브 · 인스타 · 페이스북 · 쓰레드 · 틱톡**에 올리고 텔레그램으로 알려줍니다.

| 플랫폼 | 들어가는 글 | 공개 상태 |
|---|---|---|
| 유튜브 | 유튜브 제목 (설명란 비움) | 비공개 → 폰에서 공개 전환 |
| 인스타 / 페북 / 쓰레드 | 공통 본문 | 바로 공개 |
| 틱톡 | 틱톡 본문 (텔레그램으로 따로 옴) | 틱톡 앱 **메시지 → 시스템 알림**에서 열어 본문 붙여넣고 게시 |

글 칸을 비워두면 다른 칸을 참고해 자동으로 채웁니다(AI 키가 있으면 AI 가 작성).

---

## 처음 설정 (한 번만)

### 1. 파일 넣기
- 구글 클라우드에서 받은 OAuth JSON 파일 → `bot/secrets/google_client.json` 으로 이름 바꿔서 넣기
- `bot/config.yaml` 열어서 값 채우기 (시트 ID, 앱 ID/시크릿, 텔레그램 토큰)

### 2. 각 개발자 사이트에 '로그인 후 돌아올 주소' 등록
아래 주소를 **쓰레드·틱톡 앱**에 등록합니다.

```
https://tjdals423-netizen.github.io/SNS_UPLOAD/callback.html
```

- (페북+인스타는 등록 필요 없음 — 그래프 API 탐색기 토큰 사용)
- **Threads 앱**: 사용 사례 → Threads API → 설정 → *콜백 URL 리디렉션*
- **TikTok 앱**: Login Kit → *Redirect URI*

### 3. 계정 연결
`bot/setup.bat` 더블클릭 → 메뉴 번호대로 진행

1. 구글 (폼 만든 계정)
2. 유튜브 → A, B, C 각각 한 번씩
3. 페이스북 + 인스타 → 페이지를 관리하는 페북 계정마다 한 번 (페이지별로 A/B/C 지정)
4. 쓰레드 → A, B, C 각각 (브라우저에서 해당 계정으로 로그인된 상태에서)
5. 틱톡 → A, B, C 각각 (마찬가지)
6. 텔레그램
7. 점검 → 전부 ✅ 인지 확인

> 로그인 정보는 `bot/secrets/` 에만 저장되고 GitHub 에는 올라가지 않습니다.

## 실행
`bot/start_bot.bat` 더블클릭. 창을 켜두면 1분마다 시트를 확인합니다.

**PC 켤 때 자동 실행**: `Win + R` → `shell:startup` → 열린 폴더에 `start_bot.bat` 바로가기 넣기

## 결과 확인 / 재시도
- 폼 응답 시트 오른쪽에 `상태`, `결과_유튜브` … 칸이 자동으로 생깁니다.
- 실패하면 최대 3번 자동 재시도. 바로 다시 올리려면 해당 `결과_…` 칸을 지우면 됩니다.

## 집 PC 로 옮길 때
1. 이 저장소를 내려받고
2. 기존 PC 의 `bot/config.yaml` 과 `bot/secrets/` 폴더를 그대로 복사
3. `start_bot.bat` 실행

⚠️ 두 PC 에서 **동시에** 켜두지 마세요 (같은 영상이 두 번 올라갈 수 있음).
